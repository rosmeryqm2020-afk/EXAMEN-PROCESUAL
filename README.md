# Sistema de Turnos de Estudiantes

#  Descripcion
Este programa en C++ permite gestionar turnos de estudiantes utilizando una cola (FIFO). 
Se pueden registrar, atender, mostrar y buscar estudiantes.

# Estructura usada
Se utilizó una lista enlazada simple.

# Justificacion
Permite insertar al final y eliminar al inicio de manera eficiente, simulando una cola.

# Complejidad
- Inserción: O(1)
- Eliminación: O(1)
- Búsqueda: O(n)

# Como ejecutar

```bash
g++ main.cpp -o programa
./programa
